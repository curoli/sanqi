# Sanqi（三棋）

Sanqi（中国語で三棋、Sānqí、「三つのチェス」の意）は、駒同士の連携が重要な役割を果たす、2人用の戦略ゲームです。

白と黒の2人が交互に手を指します。白が先手です。

チェス盤を使います。各プレイヤーは16個の駒を持ち、自分に近い2列に並べます。

![図1：初期配置](images/sanqi-start.svg "図1：初期配置")

1手には3個の駒が関わります。動く1個を攻撃駒、動かない2個を支援駒と呼びます。どの駒も、攻撃駒にも支援駒にもなれます。

2個の支援駒は、そのちょうど中間にある支点を定めます。支点は、マスの中心、隣接する2マスの境界の中点、または4マスが接する角に位置します。

攻撃駒は支点の反対側へ移動し、支点が出発マスと到着マスのちょうど中間になるようにします（図2）。攻撃駒が最初から支点上にある場合でも、出発マスと到着マスが同じであってはなりません。

移動距離に制限はありませんが、到着先は盤内でなければなりません。移動方向は盤の辺や対角線に平行である必要はなく、さまざまな方向に移動できます。

到着マスは空いているか、相手の駒が置かれていなければなりません。相手の駒がある場合は、その駒を取り、盤から除きます。

![図2：可能な指し手の例](images/sanqi-moves.svg "図2：可能な指し手の例")

合法手がないプレイヤーは負けです。例えば、残りの駒が3個未満になった場合などです。また、自分の駒同士が移動を妨げ合い、指せる手がなくなって負ける場合もあります。

![図3：合法手がない局面の例](images/sanqi-blocked.svg "図3：合法手がない局面の例")
